# Drop the workbook here

Upload `RBB_League_History.xlsx` into this folder to update the website.

**From a browser, no terminal needed:** open this folder on github.com, click
**Add file → Upload files**, drag the workbook in, and commit. A robot then reads
it, updates the site's data, and the site redeploys itself a minute or two later.

Replacing the file is fine and expected — upload the new copy with the same name and
it overwrites the old one.

The file name must end in `.xlsx`. Anything else here is ignored.
